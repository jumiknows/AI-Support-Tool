# Security

This repository is a prototype that can process sensitive conversation text.

- Do not commit session logs, credentials, or real participant data.
- Use synthetic data in issues, screenshots, and demos.
- Keep `SUPABASE_SERVICE_ROLE_KEY` server-only.
- Apply the latest Supabase migrations before testing.
- Do not use this prototype for emergencies or clinical care.

If you find a vulnerability that could expose stored messages or credentials, report it privately rather than posting the data in a public issue.
